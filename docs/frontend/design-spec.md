# Co-Work 界面设计规范

用户确认参考 macOS 原生应用；本版按 Swiss / International typographic 方向执行。使用浅色、Apple 蓝、双栏与可展开回答详情，重点是连续阅读、真实来源和可见的工具执行状态。

## 视觉参数

| 元素 | 规范 |
| --- | --- |
| 背景 | #FFFFFF 内容区、#F7F7F8 侧栏、#FAFAFB 回答详情 |
| 正文 | #1D1D1F，次级文字 #86868B |
| 强调 | #0071E3；只用于主操作、焦点、链接和进行中状态 |
| 边线 | #D2D2D7，1px |
| 字体 | Avenir Next / Helvetica Neue 标题，PingFang SC / Hiragino Sans GB 正文 |
| 正文 | 14–16px；阅读区约 1.8–1.95 行高 |
| 标题 | 页面 20–24px；空状态标题约 30px |
| 圆角 | 控件 3–4px；内容面板优先使用边线和留白 |
| 布局 | 1440×960 主稿、1280×800 验证；侧栏约 250px、回答详情约 330px |

不得使用 Apple 标志或仿系统窗口红黄绿按钮。没有装饰性渐变、大面积玻璃背景或营销首页。

## 页面与状态

### 页面文案

文案必须直接服务于当前操作或状态，避免解释性的无意义描述、重复标题含义或泛化的产品口号。凡是不能帮助用户决定下一步、理解处理结果或识别限制的说明文字都不应出现。例如“选择知识库中已就绪的两篇论文”“回到工作台让智能助理结合论文原文检索证据”“服务连接、运行指标与知识库状态”等句子，应改为具体的操作标签、当前状态或错误处理提示；没有额外信息时直接省略，不用占位文案填充空间。

### 工作台

左栏上方为“研究工作台”品牌、新建会话和导航；中部历史会话；下方显示连接与资料数量。聊天页不重复展示项目标题，只保留对话内容与输入框；空白对话上方标明当前为智能助理，回答详情从回答操作进入。

空状态只保留“开始一轮论文研究”大标题，以及固定在输入框上方的上传论文、比较论文两个直接入口。英文小标题、解释句和模式说明全部省略。知识库检索由智能助理按需调用，不单独提供模式入口。回答支持 Markdown、公式/表格的原生渲染，引用位于回答边界内。复制入口提供原文；回答详情展示引用来源与执行过程。正文不显示 API Key、Python 类型或内部路径。

智能助理保留多轮记忆，执行时显示当前工具和阶段，完成后展示最终答案。工具失败必须有明确文本，不将一次失败错误地显示为整个 Agent 已终止。

### 文档与论文分析

上传区展示格式、大小与数量限制。列表显示名称、大小、片段数、状态和操作。进度按文件数和实际阶段呈现。失败可重试；删除对话框说明文档索引将移除，历史引用快照保留。

选择一篇论文生成摘要，选择两篇论文执行对比。生成一个智能助理会话，结果在工作台显示。对比结果为结构化表格；缺失字段显示“未提取到”，不由前端补齐。

### 回答详情

引用：编号、论文/文件名、页码、检索片段、原文下载。页码 null 显示“未提供页码”。原文件删除后保留片段，下载入口显示不可用。

执行：默认突出当前步骤与工具，Thought/Action/Observation 可展开；完成后显示耗时和可得 Token。小窗口允许下移或收起，优先保证正文宽度。

### 系统状态

应用启动时读取 `.env` 中的 `DEEPSEEK_API_KEY`，不重复要求用户输入。明确 DeepSeek API 与本地知识库的边界；配置状态不等于连接成功，连接探测由“检查连接”主动触发。展示历史请求数量、真实总耗时和当前进程工具指标。未采集值保持未提供，未评测指标不显示虚构数字。

## 原型与应用的关系

原型为离线可浏览 HTML/CSS，顶部场景切换属于设计评审工具，不进入实际应用。原型所有回答、论文片段、统计数字和进度均为演示数据。HTML 是排版源文件，PNG 是渲染结果。

| PNG | 场景 | 评审重点 |
| --- | --- | --- |
| empty.png | 空白会话 | 起始引导、阅读空间 |
| answer.png | 带引用回答 | 正文层级、回答详情 |
| agent.png | Agent 执行 | 过程透明、完成前状态 |
| documents.png | 文档管理 | 导入进度、部分失败 |
| compare.png | 论文对比 | 并排字段、缺失值 |
| status.png | 系统状态 | 配置与探测、真实指标口径 |

实际 Streamlit 优先使用原生布局、对话框、fragment、chat_input 和主题设置；CSS 只集中在 theme.py，以公开容器和稳定 testid 控制必要的样式。不承诺与 HTML 原型逐像素一致。

## 可用性检查

- 1440×960 与 1280×800 无水平溢出；内容区可以正常垂直滚动。
- 中文、长文件名、表格和长答案不遮挡操作。
- 原型场景导航、回答详情入口、引用入口和论文分析导航可点击。
- 键盘焦点可见，按钮有文字或 aria-label。
- 原型不能让用户误以为已连接真实模型；实际应用不得显示原型中的演示指标。
